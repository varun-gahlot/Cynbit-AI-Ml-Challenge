# Submission note

**Project:** Cynbit Lead Intelligence & Qualification Assistant

**Problem:** Incoming enquiries may span multiple services and products. A consistent first-pass triage can help a human team route enquiries, prioritize follow-up, and prepare relevant responses.

**What is included:** an AI Opportunity Report, Technical Approach Report, runnable Streamlit proof of concept, requirements, and synthetic sample data.

**Demo:** run `streamlit run app.py`, load the sample lead, analyze it, inspect the score rationale, and edit the proposed follow-up. The prototype uses rules/keywords intentionally; it is not a trained ML model and does not send messages or update a CRM.

**Next step:** validate the workflow and scoring rubric with Cynbit stakeholders, then run a shadow pilot against approved historical data before production integration.
